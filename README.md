# Multimodal Fake News Classification

This repository contains our course project on **multimodal fake news detection**, combining text and image analysis to classify news as *real* or *fake*.  
The project explores dataset analysis, benchmarking, custom models, and comparative evaluation across multiple deliverables.

---

## 🚀 Project Overview
The spread of fake news often involves misleading text and visuals.  
Our goal is to design classifiers that can analyze both written content and accompanying images to identify deceptive news reliably.  
We use the **Fakeddit dataset** for experiments, exploring multimodal detection with models such as BERT, CNNs, and GPT-based architectures.

---

## 📂 Deliverables

### Part #1: Data Exploration & Literature Review (DDL: 9/14/2025)
- Dataset familiarization (text, image, metadata)
- Exploratory analysis of class balance, missing data, multimodal alignment
- Literature review of recent multimodal fake news methods

### Part #2: Benchmarking (DDL: 10/2/2025)
- Implement baseline models (text-only, image-only)
- Reproduce one published multimodal method
- Evaluate with accuracy, precision, recall, and F1-score

### Part #3: Development of Own Method (DDL: 10/23/2025)
- Propose and implement a novel multimodal classifier
- Experiment with cross-modal consistency and alignment techniques

### Part #4: Comparative Evaluation & Report Writing (DDL: 12/4/2025)
- Compare baselines, published methods, and our model
- Document improvements, limitations, and failure cases
- Write a polished IEEE-format final report
